# Personal Portfolio Website

## Overview

This project is a responsive personal portfolio website developed using **HTML5** and **CSS3**. It showcases my education, technical skills, projects, achievements, experience, and contact information through a modern and user-friendly interface.

The website follows semantic HTML, responsive web design principles, and accessibility standards to provide a clean and professional user experience across different devices.

## Features

* Responsive navigation bar
* Hero section with profile image and social media links
* About Me section
* Education section
* Skills section
* Projects section (3 projects)
* Experience section
* Achievements section
* Contact form
* Responsive design for desktop, tablet, and mobile devices
* Hover effects and smooth animations
* Clean card-based user interface

## Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Variables
* Media Queries

* Semantic HTML structure using:

## CSS Requirements Satisfied

* External stylesheet (`style.css`)
* CSS Custom Properties (`:root`) used for colors and theme
* Layout implemented using **Flexbox**
* Responsive design using two breakpoints:

  * Tablet (≤768px)
  * Mobile (≤480px)
* Interactive effects:

  * `:hover`
  * `:focus`
* CSS transitions
* Fade-in animation using `@keyframes`


## Why Flexbox?

Flexbox was selected because the website primarily consists of one-dimensional layouts such as:

* Navigation bar
* Hero section
* Skills cards
* Project cards
* Experience cards
* Responsive card layouts

Flexbox provides simple alignment, spacing, wrapping, and responsive behavior while requiring less code than CSS Grid for this type of design.

## Responsive Design

The website adapts automatically to different screen sizes.

### Desktop

* Side-by-side hero layout
* Multi-column cards

### Tablet (≤768px)

* Stacked hero section
* Single-column cards
* Wrapped navigation

### Mobile (≤480px)

* Compact navigation
* Smaller typography
* Responsive buttons
* Optimized spacing
  
## Accessibility

The website follows accessibility best practices by:

* Using semantic HTML elements
* Maintaining a logical heading structure
* Providing descriptive image alternative text
* Associating every form field with a label
* Ensuring keyboard focus visibility
* Using readable color contrast
